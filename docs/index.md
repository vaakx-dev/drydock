Welcome to the Drydock wiki.

Drydock is a small TypeScript runtime for composing long-lived systems from scoped services and plugins.

## Start here

- [Runtime model](model.md): contexts, services, scopes, plugins, and loaders.
- [Lifecycle](lifecycle.md): activation, recomposition, failure, and cleanup.
- [Packages](packages.md): the package map and dependency boundaries.
- [API reference](api/): the public API for every package.
- [Boundaries](boundaries.md): what Drydock owns and what stays with the host.

Drydock is early-stage software. Public APIs may change.
